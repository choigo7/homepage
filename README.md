# 햇살 교재몰

유치원 교재를 등록하고, 학부모가 회원가입 후 상품을 골라 결제할 수 있는 쇼핑몰입니다.
정적(static) 단일 페이지로 만들었어요. 서버나 데이터베이스가 필요 없어요.

## 실행 방법

- 가장 쉬운 방법: `index.html` 파일을 브라우저로 열기
- 또는 정적 서버로 실행하기:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

외부 폰트나 CDN을 쓰지 않아서, 오프라인에서도 열립니다.

## 기능

- 교재 목록: 샘플 교재 6권 (한글, 수학, 영어, 미술, 과학, 음악)
- 검색, 연령 필터(만 3세 / 만 4세 / 만 5세 / 공통), 과목 필터
- 상품 상세 보기 (설명, 수량 선택)
- 회원가입 / 로그인 / 로그아웃 (브라우저에만 저장)
- 장바구니: 담기, 수량 +/-, 삭제, 합계
- 배송비 3,000원, 30,000원 이상 무료배송
- 결제: 받는 사람, 연락처, 배송지 주소, 결제 방법(카드 / 간편결제 / 계좌이체)
- 주문내역: 로그인한 사용자의 주문 목록, 상태 `결제완료`
- 교재 등록 (관리자 탭): 새 교재 등록, 수정, 삭제 — 등록한 교재는 상품 목록에 바로 나타납니다

## 결제 안내

**결제는 모의결제입니다.** 실제 카드 결제가 되지 않고, 돈이 빠져나가지 않아요.
실제 운영을 하려면 PG(결제 대행사) 연동이 필요합니다.

## 기술 메모

- `index.html` 하나에 HTML, CSS, JavaScript가 모두 들어 있습니다.
- 주문, 장바구니, 회원 정보, 등록한 교재는 브라우저 저장소(localStorage)에 저장됩니다.
- 저장소가 차단된 환경에서도 화면이 하얗게 비지 않도록, 모든 저장소 접근을 try/catch로 감싸고 메모리 저장으로 대체합니다.
